# wpf-gestion-bancaire

**FR** — Application de bureau **WPF (C#)** de gestion bancaire : création de comptes, dépôts, retraits et suivi des opérations, structurée en **MVVM** et couverte par des tests unitaires.

**EN** — A **WPF (C#)** desktop banking-management app: account creation, deposits, withdrawals and transaction tracking, built with **MVVM** and covered by unit tests.

---

## Fonctionnalités / Features

- **FR**
  - Gestion de comptes bancaires et de leurs opérations.
  - Architecture **MVVM** (séparation nette Vue / logique).
  - Projet de **tests** dédié (`GestionBanque.Tests`).
- **EN**
  - Bank accounts and their transactions.
  - **MVVM** architecture (clean View / logic separation).
  - Dedicated **test** project (`GestionBanque.Tests`).

## Stack

C# · .NET · WPF · MVVM · tests unitaires.

## Lancement / Run

```bash
# Ouvrir GestionBanque.sln dans Visual Studio 2022, puis F5
dotnet run --project GestionBanque
```
